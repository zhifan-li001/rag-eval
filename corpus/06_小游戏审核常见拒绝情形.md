# 06 · 小游戏审核常见拒绝情形

> 资料来源：微信开放文档「微信小程序平台常见拒绝情形」（developers.weixin.qq.com/minigame/product/reject.html），
> 页面最后编辑于 2026-03-25。本文按官方条目归类整理，条款编号与原文一致。

## 总则

- 除本拒绝情形清单外，开发者还应遵守《微信小程序平台服务条款》及腾讯公布的相关规则规范。
- 审核是发布前的必经环节，被拒绝后可以修改重新提交。

## 一、账号基本信息

### 1.1 名称、简介、logo、服务范围、服务标签不得

1. 侵犯他人权益，包括著作权、商标权、肖像权、名誉权等。包括使用不属于本主体的品牌、商标、标识，或与之相似的内容、特殊角标。
2. 含有商业化用语、热门小程序名称、「国家级」「最高级」等广告法明令禁止的词语，或其他无关词语。
3. 含有政治、色情、敏感、暴力血腥、恐怖，以及其他法律法规禁止的词汇和违法内容。

### 1.2 名称与简介的特别规则

- 简介必须明确介绍小程序的功能点，不能使用模糊表达。反面例子：「旨在提高用户的生活品味」「旨在提高用户的购物体验」。
- 名称和简介表达的意思必须有关联、一致，并与实际功能一致，不得含有与功能无关的搜索热词。
- 名称不能使用电话、邮件、日历、小游戏这类广义归纳词，也不能用斗地主、麻将这类通用游戏名，或其他普遍且不具识别性的词语。
- 名称不能是单个词，必须是两个词以上的组合。

### 1.3 头像 logo 的规则

- 清晰度不够不予通过：无法看清、分辨、识别图片中的文字、物体、形状等元素。
- logo 应与名称、简介保持一致。
- logo 不得包含腾讯、微信等官方品牌标识。
- logo 需使用透明或有色背景；若使用白色背景，必须使用有色边框。

### 1.4 服务范围和服务标签

- 设置的服务标签应与所选服务范围保持一致，标签不能超出服务范围。
- 例如服务范围是家政，服务标签写美食，属于不一致。

## 二、服务类目审核

- 服务类目是开发者按小程序提供的服务类型和内容，在平台分类分级表格中选择的行业范围。
- 类目必须和实际提供的服务一致。类目对应页面中的核心内容必须与类目一致。
- 必须保证用户在该页面能使用该类目对应的服务，不得隐藏，不得经过多次跳转。
- **一旦选择了游戏类目，该类目不可修改变更为其他小程序类目。**
- 类目对应的页面链接必须能正常打开，不得加载非法信息、恶意或色情广告、侵犯他人权益的内容。

## 三、整体审核规则

### 3.1 基本功能

- 实际提供的功能点必须与简介一致。
- 所有服务类目功能必须在小程序首页得到体现：从首页必须能直达，或经过两次点击到达所有已提交的类目页面。
- 实际服务不得属于尚未开放的服务范围，不得超出平台已开放的类目库。
- 若存在隐藏功能或付费功能（仅充值可见、仅会员可见），不得含有色情、暴力、政治敏感或其他违法内容，且开发者提供的测试号必须能完整呈现和体验该功能。
- 功能应具有使用价值，不能过于简单。例如只有一个页面、只有一个按钮，属于过于简单。
- 未经腾讯授权，不得提供与微信客户端相同或类似的功能，例如朋友圈、漂流瓶。
- 未经允许或授权，不得展示和推荐第三方小程序，例如做小程序导航、小程序互推、排行榜。
- 功能的使用不得以关注或使用其他号为条件。

### 3.2 页面内容

- 不得存在诱导类行为：诱导分享、诱导添加、诱导关注公众号、诱导下载。要求用户分享、添加、关注或下载后才能操作的程序会被拒绝。用利益诱惑诱导分享、用夸张言语胁迫引诱分享，也属拒绝情形。
- 不得主要为营销或广告用途：内含空白广告位、招商广告等会被拒绝。页面中广告展示比例超过 50%、广告遮挡功能，都会被拒绝。
- 不得存在对用户产生误导、引发恐惧心理、严重破坏体验或损害用户利益的内容。
- 不得存在测试类内容，例如算命、抽签、星座运势。
- 不得存在虚假、欺诈类内容：虚假红包、虚假活动、销售侵害他人权益的商品、仿冒腾讯官方或他人业务。
- 不得含有传播骚扰信息、广告信息、垃圾信息的内容。
- 图片上不能含有广告、网址或虚假内容。
- 代替用户发表、发送、转交任何内容前，必须征得用户明确同意和授权。
- 服务提供者必须提供过滤不当内容的措施，例如对色情、赌博等违规词汇做过滤提示。
- 不得存在误导或错误暗示与腾讯有合作、投资、背书关系的内容。

### 3.3 违法违规内容

- 反对宪法确定基本原则的，危害国家安全、泄露国家秘密、颠覆国家政权、破坏国家统一的，损害国家荣誉和利益的。
- 任何带有虚假、欺诈内容的。
- 任何召集、推销、鼓动犯罪或有明显侵犯社会善良风俗行为的。
- 包含法律法规禁止传播内容的。
- 含有煽动性涉政言论、散布谣言、扰乱社会秩序、破坏社会稳定的。
- 含有色情素材，或涉嫌宣扬传播淫秽色情信息的，包括暴露图片、挑逗内容。
- 煽动民族仇恨、民族歧视、破坏民族团结，破坏国家宗教政策，宣扬邪教和封建迷信的。
- 展示人或动物被杀戮、致残、枪击、针刺或其他伤害的真实图片，描述暴力或虐待儿童的。
- 包含赌博、有奖竞猜和抽奖内容的。游戏类目如采取随机抽取方式提供虚拟道具和增值服务，不得诱导用户以直接投入法定货币或虚拟货币的方式参与。
- 诱发未成年人违反公德、违法犯罪，或妨害未成年人身心健康的。

### 3.4 可用性与完整性

- 提交的必须是完成品，可以打开、可以运行，不能是测试版。不可运行、存在崩溃、闪退、按钮无响应、文字表述不完整，都属于拒绝情形。
- 小程序自身崩溃，或造成微信客户端崩溃的，会被拒绝。
- 存在严重 Bug 的会被拒绝，例如无法添加和打开、无法返回和退出、卡顿严重。
- 若存在账号体系，必须提供测试号，包含账号和密码，且能体验所有功能。

### 3.5 用户隐私和数据安全

- 收集和使用用户任何数据时，必须明确告知用途，取得用户明确同意和授权，并在授权范围内使用。用户注销账号后应删除相关数据。数据包括地理位置、通讯录、手机号码等。
- 不得在任何页面请求或诱导用户输入微信用户名或密码。
- 不得将搜索小程序功能加入小程序。
- 不得将收集到的用户数据出售、转交、交易、越权披露或泄露。
- 未经用户授权同意，不得显示用户头像、昵称等数据。
- 不得要求用户降低手机操作系统安全性（如 iPhone 越狱、Android ROOT）后才能使用。
- 若有追踪地理位置的功能，必须提供退出该追踪的功能和明确指示。

### 3.6 技术实现规范

- 需要提供小程序文档和说明。
- 禁止视频、音乐、语音等多媒体自动播放。
- 安装或运行其他可执行代码的程序会被拒绝。
- 违规加载或更新代码会被拒绝。
- 若有账户系统，必须提供能正常使用且易于发现的「退出」账户选项。

### 3.7 UI 规范

- 需符合 WeApp UI 规范。
- 页面内的浮层和弹窗必须可以关闭。
- 界面必须遵守微信的外观和功能，不得提供改变微信外观和功能的产品体验。
- 界面不得模仿系统通知或警告来诱导用户点击。
- **小游戏必须在游戏开始画面显著位置标明游戏的批准文号、网络游戏出版号以及著作权登记号，并全文登载《健康游戏忠告》。**

## 对单词萌宠的直接含义

- 名称不能只叫「单词萌宠」以外的单个通用词，使用「单词萌宠」这类两个词以上的组合是合格的。
- 简介必须写清功能点，不能写「提升英语学习体验」这种模糊表述。
- 选择游戏类目后不可再改成其他类目，所以注册时类目要想清楚。
- 必须准备测试号（含账号密码且能体验全部功能），否则有账号体系会被拒。
- 游戏开始画面必须标注著作权登记号等信息，这与软著办理直接相关。
- 不得诱导分享，所以「分享给三个同学解锁宠物皮肤」这类设计会被拒。
